# Welcome to Audit CMS

This is your self-contained markdown content management system built with Next.js 16 and Cache Components.

## Features

- **MDX Support**: Write content in Markdown with JSX components
- **Shiki Syntax Highlighting**: Beautiful code blocks with VS Code themes
- **GitHub Sync**: Auto-commit changes to your GitHub repository
- **Live Editing**: Edit content directly in the browser
- **Nested Documents**: Organize content in folders with parent/child relationships

## Code Example

Here's a TypeScript example with syntax highlighting:

```typescript
interface Document {
  id: string
  title: string
  content: string
  metadata: {
    tags: string[]
    status: 'draft' | 'published'
  }
}

async function fetchDocument(slug: string): Promise<Document> {
  const response = await fetch(`/api/documents/${slug}`)
  return response.json()
}
```

## Getting Started

1. Navigate to the **Editor** to create and manage documents
2. Use the **Docs** section to view published content
3. Configure GitHub sync in your `.env.local` file
